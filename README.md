# NYC Citi Bike: Historical Ridership and Station Demand Analysis

## Project Overview

This project explores historical NYC Citi Bike ridership data using Google BigQuery, with the goal of developing a dimensional data warehouse and a Tableau dashboard. The proposed dashboard will help identify ridership trends, station demand, trip duration patterns, and differences in usage between membership groups.
